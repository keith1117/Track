# Track：英文优先、中文后续开放的设计

日期：2026-10-10

状态：用户于 2026-10-10 确认本书面设计，并于 2026-10-12 确认计划、顺序执行及去字副本。产品实现、双语言浏览器验收和一次独立审查修补已完成；69 项本地测试通过。GitHub 同步与远端检查记录见实施计划及 QA 记录。main 与部署保持不变。

## 1. 目标与边界

在现有 Track 仓库维护一套训练逻辑和界面，先向用户提供英文，保留中文用于内部预览，之后通过发布配置开放中文。修复功能时不需要分别修改两套项目。

本次包括：18 个现有页面、七类训练入口、39 个动作的名称、导航、提示、表单标签、读屏文案、日期和数字格式，以及语言发布配置。

保持不变：训练和动作 ID、已保存的训练历史、训练完成逻辑、Free / Track Pro 的原型交互、六类人体轮廓和高亮、39 个动作的现有配图。有氧仍不高亮。

本次不包含：真实产品上线、真实订阅购买、账号或服务器迁移、新增支付平台、动作姿势修正、中国大陆独立运营方案、切换前端框架。用户已有的根目录 README.md 产品说明修改不纳入提交。

## 2. 已确认的选择

采用一个仓库、一套业务代码、独立语言词典。与复制两个仓库相比，它避免训练逻辑和修复重复维护；与长期维护英文/中文分支相比，它避免功能和素材分叉。语言是运行配置，不是业务分支。

当前实现是无需安装构建依赖的普通 JavaScript 页面。保持此形式，不引入框架或翻译服务。

## 3. 文件职责与加载方式

新增或调整以下边界：

- `mobile/locales/en.json`：完整英文词典，作为默认语言和回退语言。
- `mobile/locales/zh-CN.json`：现有中文词典，不删除当前中文内容。
- `mobile/scripts/build-locales.js`：使用 Node 内置功能校验词典并生成浏览器可直接加载的消息文件；不安装额外依赖。
- `mobile/locales/messages.js`：由上述两份 JSON 生成并提交的运行时消息文件，不人工编辑。这样保留直接打开 index.html 的预览能力，不依赖 file:// 下的 JSON 请求。
- `mobile/i18n.js`：提供语言选择、文本插值、英文单复数、数字和日期格式化。只处理显示，不保存或修改训练数据。
- `mobile/release-config.js`：默认语言、公开语言、是否允许内部预览、地区显示配置。
- `mobile/app.js` 与 `mobile/index.html`：调用词典和格式化工具，保留现有页面和事件入口。
- `mobile/styles.css`：适配英文长度，并将身体部位插画与真实文字分离。
- `mobile/tests/`：词典、配置、双语言页面和数据不变性测试。
- `mobile/README.md` 与 `AGENTS.md`：记录预览方式、词典维护方式、语言和 GitHub 发布规则。

词典是唯一可编辑的文案来源。自动检查对比生成结果，防止 JSON 与已提交的运行时文件不同步。页面脚本按发布配置、消息文件、国际化工具、训练核心、页面脚本的依赖顺序加载。

## 4. 文案与数据分离

以稳定键名组织文案，例如 `nav.home`、`body.chest.name`、`exercise.bench-press.name`、`workout.save`。两份词典具有相同键、相同插值参数；需要单复数的英文文案具备相应变体。

不得通过全局字符串替换、翻译后再查找动作名称、或每个页面复制一套中英文 HTML 实现多语言。每个页面仍只保留一个渲染函数。

时间、次数、重量、距离作为结构化值保留，显示时组合为本地化文案。现有 `70 kg`、`20 次`、`30 分钟` 等原型展示字符串需要与数值分开。训练记录继续使用原有动作 ID、ISO 时间和 kg/km 基础单位；不改 `track.training-history.v1` 的已有数据格式，也不清除浏览器存储。

动态句子在词典中保留完整语序，用参数插入次数、部位、重量等值，不拼接中文语序。词典内容是文本而非 HTML；插入页面的动态文本按现有渲染边界统一转义，避免重复转义或把用户输入解释为标签。

全部产品文案包括：页面内容、按钮、空状态、推荐标签、提示消息、表单 placeholder、aria-label、图表标签、标题、页面说明和示例社区文案。用户名、用户输入和用户自己发布的内容不自动翻译。

`document.documentElement.lang`、导航读屏名称和页面元信息随实际显示语言同步。英文发布不得出现原型中文漏译或原始词典键。

## 5. 英文发布与中文预览规则

默认配置：`defaultLocale = en`、`publicLocales = [en]`、`allowLocalePreview = false`。英文和简体中文是此次仅支持的两种语言；无效语言请求回到英文。

公开模式只显示英文，不出现中文选择入口。浏览器语言是中文也不能自动越过公开语言列表；之前保存的中文偏好不能绕过该限制。运行时可用语言由配置白名单决定。

内部预览由本地服务的显式环境开关 `TRACK_LOCALE_PREVIEW=1` 开启。服务仅在此模式返回允许预览的发布配置，页面才展示内部语言切换控件并接受 `?locale=zh-CN`。直接打开文件或普通启动服务仍默认英文，不启用预览。

语言优先级：被当前模式允许的显式预览请求、被允许的已保存语言偏好、被公开语言列表允许的浏览器偏好、默认英文。语言偏好使用独立存储键，与训练历史无关；存储不可用时仍可正常预览。

切换语言保留当前页面、选中的部位和动作、会员状态、未保存训练输入、完成组、历史筛选和已保存记录。语言切换后更新显示文字，不重建初始训练状态。

中文公开时通过同一份配置将 `publicLocales` 改为 `[en, zh-CN]`，增加用户语言设置入口。中文不得依赖永久的中文分支。

内部预览开关不是身份验证或保密机制。词典在同一仓库维护；本次不把中文文案视为需保密内容，也不声称客户端开关可以限制有意查看源文件的人。

缺失中文键时内部预览回退到英文，并在开发检查中报告问题；英文基准键缺失、参数不一致或生成文件过期均阻止检查通过，不能带着错误发布。

## 6. 图片卡片与视觉保持

当前六张身体部位卡片的中文标题、状态和部分推荐标签直接位于图片中。它们不能靠翻译词典改变，因此必须把插画与文字分离。

保留 `body-parts-reference.png` 和 `body-parts-arms-core.png` 原文件不变。优先通过每个部位的显示区域裁切，仅呈现现有的人体插画；不显示原图中的中文标题、状态、标签、箭头或卡片边框。卡片边框、标题、推荐标记、状态和箭头由真实 HTML/CSS 构成。

每个部位继续是独立的真实按钮。六张卡片共用尺寸、字号和间距规则，银灰轮廓与原有绿色目标部位保留。有氧继续使用现有无高亮跑者和真实文字。

本次不重新绘制解剖结构。若某一插画无法在不包含中文、也不裁掉必要身体轮廓的情况下分离，反馈具体卡片并请求素材处理方向，不擅自生成不同身体造型。

胸部八个动作继续复用已确认图像的器械显示区域，其余动作继续使用现有独立素材。不要重新生成或扩大动作细节修正范围。

英文和中文均检查 320、390、430 CSS 像素宽度，以及桌面手机框。英文长标签允许自然换行，不通过缩小到难读的字号解决。保持控件至少 44px、输入字号至少 16px、页面缩放、安全区、焦点和减少动态效果支持。

## 7. 语言与地区不是同一配置

此次默认地区显示配置为通用、kg/km 基础单位，独立于语言选择。英文不自动代表美国，也不自动将历史重量转换为磅。

日期和数字使用选择的语言格式化；记录的时间戳不修改。涉及时间边界的训练统计不因翻译而改变现有计算逻辑。

价格不靠翻译或货币符号替换生成。当前 ¥298 是原型示例，不是已确认的英文市场售价。通用地区配置未设售价，两种语言都显示“定价尚未确定”的对应文案，不虚构美元售价。现有 ¥298 仅作为明确标记的中国地区原型示例数据保留，只有显式选择该地区配置才显示；切换语言本身不改变价格配置。不新增地区选择界面，原型配置从发布配置读取，不在页面模板里写金额。

本次不增加真实付款或自动单位换算。以后确定运营地区、价格和单位偏好时，在独立地区配置和功能中实现，不复制产品逻辑。

## 8. GitHub 与发布管理

`dev` 作为日常开发和验证分支，`main` 作为未来经过验收的稳定发布分支。临时工作分支使用 `codex/` 前缀，按功能命名，不按语言创建永久分支。

本轮设计文档以及后续获批准的实现都提交到当前 `dev` 并同步对应 GitHub 仓库。只提交相关文件，保留用户其他本地修改。

同步 `dev` 不表示正式上线。不得在此次任务自动合并 `main`、修改 GitHub 默认分支、创建正式 release/tag、开启自动部署或更改仓库保护设置。正式发布通过审核和单独的发布确认进行。

建议后续发布记录：`v1.0.0` 仅公开英文，`v1.1.0` 在中文检查通过后开放中文。这些是示例发布安排，不是本轮创建的版本。

每次完成获批准的改动并检查通过后，提交相关代码和素材，推送 `dev`，验证远端提交并向用户提供链接。远端分叉、认证问题或保护规则阻止同步时说明实际状态，不强制推送或绕过限制。

## 9. 验收标准

1. 正常启动或直接打开页面时默认英文；中文浏览器偏好和直接请求中文不能绕过公开语言配置。
2. 显式启用本地预览后可查看中文；关闭预览后恢复公开语言规则。
3. 两份词典键和参数完整，生成文件一致；英文渲染没有中文漏译、原始键、undefined 或 NaN。
4. 英文与中文分别覆盖全部 18 页和 Free / Pro 状态；七个训练入口和 39 个动作配图仍正确对应。
5. 保存训练、添加组、输入重量、完成组和筛选历史的现有检查继续通过；语言切换不丢失未保存输入或已有历史。
6. 六张身体部位卡片不再依赖图片中的中文，保留原图插画和原文件；有氧无高亮。
7. 两种语言在三种手机宽度下没有横向溢出、文字遮挡、图像挤压或末尾内容被固定控件覆盖。真机触控与软键盘验证仍单独标记，不用桌面模拟代替。
8. 页面语言、导航、表单标签、提示和读屏文案同步；日期/数字正确本地化，历史数据和基础单位不变。
9. 通用英文原型不展示未经确认的美元价格，仍明确区分原型与真实付费功能。
10. 相关文档、词典、代码、测试和素材同步到 GitHub 的 dev；main 与实际部署保持不变。
