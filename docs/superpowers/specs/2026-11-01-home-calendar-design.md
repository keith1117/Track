# Home 单屏与 Calendar 打卡

用户要求先生成效果图，随后明确要求开始 implement。本记录落实已展示的两张效果图，记录实施选择，不把它说成用户逐字审阅过的文档。

## 目标与方案

采用紧凑的图文并排卡片：Home 顶部合并连续训练信息，保留主标题、完成数、Daily strain、AI、六肌群加有氧及四项底栏。减少重复标题与说明，不删除功能或缩放整页。备选的缩小全部字体、删除 AI/有氧入口不采用，因为不符合效果图和可访问性要求。

Calendar 留在 Level，已保存训练日显示绿色底、日期和清晰的独立勾选。空白、未保存及未来日期不显示勾选。不增加手动签到/补签、休息推断或历史样例，继续使用现有本地日期、同日去重和历史保存逻辑。

## 约束与实施选择

- 原生 JS/CSS，原始 PNG、裁切、七个稳定 ID、全部动作和训练数据结构不变。有氧仍灰白，Home 原肌肉高亮仍绿色，Level 等级配色不变。
- 英文基线与中文内部预览词典一起更新并生成；不改变公开语言白名单。简短 Home 状态单独使用本地化键，不替换已渲染字符串。
- Home 保留会员和语言预览控件；内部预览时并排集中为一行，保留文字标签的辅助技术语义及至少44px点击高度。这是实现者为额外调试控件所作的布局选择，效果图本身没有这些控件。
- 默认字号目标：320×740、390×844、430×932 的 Home 七入口全部可见，无遮挡和横向溢出。大字号、极矮高度和横屏允许安全滚动，不能截断内容或禁用缩放。
- Calendar 提高日期和勾选可读性；Level 在空间不足时允许滚动，不牺牲摘要、肌群入口或44px导航控件。
- 保留 Free/Pro 入口和门槛，语言/模式切换、Home/Level 浏览不清空未保存输入、筛选或历史。示例等级、连续天数及 Strain 保留明确的示例标记。
